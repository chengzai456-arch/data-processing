# 考勤数据处理平台 — 预防机制说明

## 新增的预防机制

### 前端（page.tsx）

| 机制 | 说明 |
|---|---|
| **文件缺失检查** | 上传前检查必填文件是否都已匹配，未匹配时给出中文提示 |
| **Excel解析容错** | 单个文件解析失败不影响其他文件，记录错误后继续 |
| **服务器返回容错** | 后端返回非JSON时，前端显示原始错误文本 |
| **错误详情展示** | 后端返回的 detail 字段一并展示给用户 |
| **自动下载** | 处理成功后自动弹出 Excel 下载 |

### 后端 API（route.ts）

| 机制 | 说明 |
|---|---|
| **JSON数据校验** | 检查是否有工号字段，过滤无工号的非法行 |
| **Excel转换容错** | jsonToBuffer 失败时返回空 Buffer，不崩溃 |
| **Supabase容错** | 创建客户端失败时继续执行，不阻断数据处理 |
| **管道执行隔离** | 用 try-catch 包裹整个管道，失败时返回友好错误信息 |
| **multipart容错** | 文件上传解析失败时返回 400 而不是 500 |

### 数据处理管道（pipeline.ts）

| 机制 | 说明 |
|---|---|
| **Excel解析容错** | 解析失败时给出明确错误信息（哪个文件、什么原因） |
| **行级容错** | 每行映射用 try-catch 包裹，跳过非法行并记录日志 |
| **空数据保护** | 所有行均解析失败时抛出明确错误，不是静默返回0行 |
| **步骤级容错** | 每个步骤用 try-catch 包裹，单步失败跳过该步骤继续后续处理 |
| **规则级容错** | 每条规则用 try-catch 包裹，单规则失败不影响其他规则 |
