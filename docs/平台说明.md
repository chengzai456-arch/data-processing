## 处理流程（14步）

### 7步清洗

| 步骤 | 功能 | 输入文件 | 逻辑 |
|---|---|---|---|
| step1 | 剔除离职人员 | 离职流程.xlsx | 提取所有工号 → 从主数据中剔除 |
| step2 | 剔除未入职人员 | 花名册.xlsx | 入职日期 > 当天 → 剔除 |
| step3 | GL00工号处理 | （无） | 剔除GL502563 + 只保留白名单GL00 |
| step4 | 剔除EU人力资源部 | （无） | 部门=EU人力资源部 → 剔除 |
| step5 | 剔除GUS白名单 | GUS白名单.xlsx | 读取多Sheet所有工号 → 剔除 |
| step6 | 补签数匹配 | 补签管理.xlsx | 过滤审批状态+日期 → 按工号计数 |
| step7 | 签字报表工时 | 本周/上周/双周报表 | 按工号汇总加班工时 |

### 7条规则

| 规则 | 功能 | 说明 |
|---|---|---|
| rule0 | 休息开始/结束时间 | 匹配班次字典填充 |
| rule1 | HUB标记 | 部门含 .H / EWR.G / CNO.G |
| rule2 | 排班正确 | 6级优先级判定 |
| rule3 | 每日总工时 | 原值 + 居家办公合计 |
| rule4 | 是否日超8H | 每日总工时 > 8 |
| rule5 | 排班+打卡+缺卡 | 有班次→标准打卡2，缺卡=max(0,2-打卡) |
| rule6 | 备注覆盖 | 请假/出差/居家办公覆盖前序规则 |

## 数据流

```
用户拖入9个Excel文件
    ↓
浏览器端用 xlsx 解析（无大小限制）
    ↓
只提取必要字段，压缩 JSON
（签字报表只保留 工号+工时 两列）
    ↓
POST JSON → /api/upload/pipeline
    ↓
Vercel Serverless 跑14步处理（max 5分钟）
    ↓
返回处理结果 + 校验报告
    ↓
浏览器端用 xlsx 生成 Excel → 自动下载
```

## 数据库

处理结果不依赖数据库也可以正常工作。如需持久化，需在 Vercel 环境变量中配置：
- `NEXT_PUBLIC_SUPABASE_URL`（已配）
- `SUPABASE_SERVICE_ROLE_KEY`（未配，需手动从 gofo-gus 项目复制）
